QUERY-TO-SLIDE · DASHBOARD GUIDE

How to use the dashboard, step by step

This dashboard keeps your prescription-trend reports current. It tells you when new data has arrived, refreshes your saved reports with one click, and shows the results as headline numbers, charts and tables — no spreadsheets, no formulas, no code. Your team will give you the link; it opens in any browser.

Check data Update reports Read results
01

Start with the top bar — your three signals

The strip at the top of the screen answers one question at a glance: is everything normal right now?

  1. 1Practice-mode label — only appears when the dashboard is running on practice data (see Step 02). If you don’t see it, you’re looking at the real numbers.
  2. 2Activity light — says idle when nothing is running, pipeline running while the dashboard is busy updating reports. You can keep working while it runs.
  3. 3Latest data date — the most recent date in any of your data. If a meeting asks “how fresh is this?”, this is the answer.
02

Check whether your data is current

The Datasets section shows one card per data source. Thirty seconds here tells you whether anything needs updating.

  1. 1Data card — what the source contains, the period it covers, and how often new data arrives.
  2. 2Freshness labels — in sync means your reports already reflect this data. data updated means new figures have arrived and your reports haven’t caught up yet — that’s your cue to go to Step 03. no nulls is an automatic quality check confirming no missing numbers.
  3. 3Simulate new data — a practice button. It adds pretend future weeks so you can rehearse the update routine safely. Real reports and real data are untouched.
  4. 4Reset demo data — removes the pretend weeks and puts everything back exactly as it was. You cannot break anything with these two buttons.
03

Update your reports — three buttons, three depths

When new data arrives, the Refresh section brings everything up to date. Start with Check — it only looks, never changes.

  1. 1The three depths. Check — just tell me what’s new; looks, changes nothing. Data refresh — accept the new data so the cards update, but don’t recalculate reports yet. Full pipeline — recalculate every out-of-date report, re-check the numbers, and rebuild the slide decks. The grey hint text always explains the selected option.
  2. 2The answer banner — after Check, a sentence tells you exactly where you stand: nothing new, or which reports are out of date.
  3. 3Progress list — during a full update, each step shows a tick when finished. You don’t need to stay on the page; a summary message appears when it’s done.
Full pipeline always asks first. Before doing anything heavy, it shows you which reports will be recalculated and waits for you to confirm. If nothing is out of date, it simply tells you so and stops. You can’t accidentally launch a long job.
04

Choose and re-run saved reports

The Views section lists every saved report. Click the ones you want, then press Run selected.

  1. 1Report card — click anywhere on the card to select it; the blue outline confirms it. Click again to deselect.
  2. 2Report labels — fresh means the result already reflects the latest data; stale means data moved since it last ran. validation pass means the numbers passed their automatic quality checks. deck means a ready-made PowerPoint is waiting for you.
  3. 3Run selected — recalculates the selected reports against today’s data and opens each one’s result below. Select all grabs every report at once.
  4. 4“Data gap” card — a report that honestly cannot be built with the data we have. The card says what’s missing, so nobody wastes time wondering.
Re-running is always safe. It repeats the exact same approved calculation on the newest data — the method never changes behind your back.
05

Read your results, top to bottom

Each report you run opens as a tab. Read it like a one-page briefing: headline numbers, then the trend, then what changed, then the proof.

  1. 1Tabs — one per report you’ve opened. Click to switch between them.
  2. 2Headline numbers — the latest total with its change versus the previous period, then each segment with its share of the total.
  3. 3Download deck — a presentation-ready PowerPoint slide of this result, built from the same numbers you see on screen. The line next to it states exactly which data date the result is based on — useful for footnotes.
  4. 4Trend chart — hover anywhere to read exact values for every line at that date. Click a legend entry to hide or show that line.
  5. 5What changed — compares this run with the previous one: how many new periods arrived, and whether any earlier figures moved. No surprises hiding in a refresh.
  6. 6Quality checks — every result is automatically checked (right number of rows, no missing values, no duplicates) before it’s shown. If a check fails, the report is flagged instead of silently delivered.
  7. 7The full table — every number behind the chart, in plain rows. What you present is always traceable to this table.

07

If something looks wrong

Four situations that look like problems but usually aren’t — and what to do in each.

A banner says the data arrived in an unexpected shape (“schema drift”)
The latest data file doesn’t match the agreed format, so the dashboard pauses on purpose rather than risk wrong numbers. Nothing for you to fix — forward it to your analytics contact and hold off on updates until they clear it.
Data cards say “in sync” but reports still say “stale”
Normal half-way state: the new data has been accepted, but the reports haven’t been recalculated yet. Run Full pipeline in the Refresh section, or select the stale reports and press Run selected.
A message says contact with a running job was lost
Your browser briefly lost touch with the dashboard — the update itself is usually still running in the background. Wait a moment and reload the page; finished work will appear on the report cards.
I was practicing and want the real numbers back
Press Reset demo data in the Datasets section. The practice weeks vanish, the originals come back exactly as they were, and the demo data active label disappears. Practicing never touches the real reports.
