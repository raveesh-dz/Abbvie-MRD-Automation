# Takeaways — run_2026-06-10_001

1. **RA / JIA is Humira's dominant indication throughout the window** — 49,379 TRx in May 2026, 2.1× the next-largest indication, Crohn's disease (23,317). The rank order of the top four (RA/JIA, CD, PsA Rheum, UC) is unchanged across all six months.

2. **Every indication stepped down ~30% from December 2025 to January 2026** (range −29.4% for AS and PsA Derm to −41.0% for Uveitis). The drop is uniform across indications, pointing to a brand-level effect rather than any indication-specific shift. No documented context rule covers this pattern yet, so it is reported without attribution.

3. **Volumes have been broadly flat since February 2026** — February-to-May changes are within ±8% for every major indication (RA/JIA −5.4%, CD +0.9%, UC −0.3%), with only the small-base indications moving more (Uveitis +18.5%, GCA −11.7%).

4. **Caveat:** indication markets overlap in this source, so the columns must not be summed into a Humira total; and it is unconfirmed whether May 2026, the latest month, is provisional.
